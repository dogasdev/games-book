Game Vault 
--
Aplicação de terminal desenvolvida para o gerenciamento de jogos, criada com o objetivo de aplicar conceitos de Programação Orientada a Objetos (POO), Generics e arquitetura baseada nas camadas Service e Repository.

## Funcionalidades
- Cadastro de jogos digitais e físicos
- Listagem de jogos cadastrados
- Busca de jogos por nome
- Filtragem por tipo de jogo
- Atualização de jogos
- Remoção de jogos
- Validação de entradas
- Prevenção de jogos duplicados (mesmo nome)

## 📋 Requisitos
Para executar o projeto, é necessário:
- Java 25 ou superior
- Uma IDE compatível com Java, como IntelliJ IDEA, Eclipse ou VS Code
- Git (opcional, caso o projeto seja clonado através do repositório)

## ▶️ Como executar
1. Clone o repositório: `git clone <URL_DO_REPOSITORIO>`
2. Entre na pasta do projeto: `cd game-vault`
3. Abra o projeto na sua IDE de preferência
4. Execute a aplicação: Procure pela classe `Main` e execute o método `main()` 

Importe o projeto como um projeto Java e certifique-se de que o JDK 25 está configurado.
